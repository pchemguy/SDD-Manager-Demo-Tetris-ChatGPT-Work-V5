# Browser Tetris

A browser Tetris project covering classic play, modern piece controls, configurable locking and ghost behavior, penetrator bonuses, and settings saved through cookies and URL parameters.

Status: project preparation. The game has not been implemented.

The [project brief](docs/dev/PROJECT.md) is the current proposal for review. [Preparation tasks](docs/dev/DOCS_TASKS.md) track document approval, and the [handoff](docs/dev/HANDOFF.md) records the workflow checkpoint. See [AGENTS.md](AGENTS.md) for development instructions.

Development uses [SDD Manager](SDD-MANAGER.md). See the [AI-assisted development disclosure](AI_DISCLOSURE.md).
